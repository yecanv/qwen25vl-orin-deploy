## 关键发现:故障与图像内容相关

| 输入 | GPU 视觉结果 |

指纹特征:**内容相关(真实照片触发,平涂合成图不触发)+ CPU fp32 正常 + GPU fp16 乱码**
→ fp16 溢出类数值故障(真实照片的激活幅值远大于平涂图,与本项目敏感度扫描结论一致;
与 ViT fp32-softmax 保护岛战役同族——TensorRT 侧因 ONNX 内建 fp32 岛而免疫)。
